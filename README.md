# Virtual Dice Game (Roll Over / Roll Under)

A simple Java CLI-based betting game where players wager virtual currency on rolling a random number relative to a target value. Built to practice conditional logic, random number generation, and switch statements.

---

## 🎮 How It Works

1. **Starting Balance:** The player begins with a default balance of **$1000**.
2. **Place a Bet:** Enter the amount of money to wager on the round.
3. **Choose Game Mode:**
   * **1. Roll Over:** Bet that your target number is higher than the rolled number.
   * **2. Roll Under:** Bet that your target number is lower than the rolled number.
4. **Set Target:** Choose a target threshold between `1` and `99`.
5. **The Roll:** The system generates a floating-point random number between `0.0` and `99.99`.
6. **Result:** Win or lose your bet amount, and see your updated account balance!

---

## 🛠️ Tech Stack & Requirements

* **Language:** Java (JDK 8 or higher)
* **IDE:** Eclipse / VS Code / IntelliJ (or run directly from terminal)
* **Libraries Used:** 
  * `java.util.Scanner` (for user input)
  * `java.util.Random` (for outcome generation)
